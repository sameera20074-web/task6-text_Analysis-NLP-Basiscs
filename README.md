# VEDA TASK - Text Analysis

## 📌 Description
Analyze a given text and calculate number of words, characters, vowels, and repeated words.

## 🎯 Objective
Practice basic text processing techniques useful in Natural Language Processing (NLP).

## 🛠 Tools
Python, Jupyter Notebook, Collections.Counter

## 💡 Logic Used
- split() -> separate words
- len() -> count words & characters
- dictionary / Counter -> repeated words
- loop + vowels check -> vowel count

## 📊 Sample Output
Text: Artificial Intelligence is the future...
Words: 18, Characters: 145, Vowels: 56, Repeated: {'artificial':2, 'intelligence':3, 'is':3}

## ▶️ Run
python text_analysis.py

## 📚 Learnings
- Text preprocessing basics
- NLP foundation steps
